# gbyrka.github.io

Publish this repository's root on GitHub Pages. `index.html` redirects visitors to the games collection at `/games/` and includes the AdSense account verification metatag.

Keep `ads.txt` at the repository root so Google can read it at `https://gbyrka.github.io/ads.txt`. The redirect page itself does not load ads or analytics. Advertising units and the shared privacy policy live in the individual project repositories.
